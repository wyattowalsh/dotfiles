Zoom behavior

Sensitivity and limits

mpv zoom is logarithmic: 100% = 0, 200% = 1, 1000% = log2(10). Zoom-out never goes below the fitted view.

MKV subtitle preroll

Off by default. Enable only when subtitles disappear after seeking in some MKV files. This changes seek and subtitle behavior and can make seeks slower.
