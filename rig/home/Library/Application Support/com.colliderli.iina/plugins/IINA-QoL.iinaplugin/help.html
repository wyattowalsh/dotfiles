IINA QoL

  • Command + scroll (Shift optional): zoom at the pointer (up in, down out)
  • Command + Shift + = / -: zoom in / out at the pointer
  • Command + Shift + 1 / 2 / 3: jump to zoom presets (100 / 200 / 400% by default; editable in preferences)
  • Command + Shift + 0: reset zoom, pan, and rotation to 100%
  • Option + Command + arrows: pan while zoomed
  • Command + R: rotate video 90° steps (0 → 90 → 180 → 270 → 0)

Unmodified vertical scroll still changes speed; unmodified horizontal scroll still seeks. If the pointer cannot be read in the player, zoom is skipped and the OSD shows zoom unavailable — it never falls back to center-zoom.

The plugin menu exposes zoom in, zoom out, presets, rotate, reset, and self-test. A one-time OSD hint describes Command+scroll.
