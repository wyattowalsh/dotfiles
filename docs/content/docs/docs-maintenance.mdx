| Path | Role |
| --- | --- |
| `docs/content/docs/` | MDX runbooks |
| `docs/DESIGN.md` | Design SSOT |
| `docs/app/global.css` | Tailwind + theme |
| `lib/hub-manifest.json` + `meta.json` | Hub + sidebar |

```bash
just docs-ci    # typecheck + build + CSS health + sensitive + hub-parity
cd docs && pnpm dev
```

CSS: always `global.css` → Tailwind pipeline — never raw `fumadocs-ui/css/*` imports in TSX. Page add/rename → update **both** `meta.json` and `hub-manifest.json`.
