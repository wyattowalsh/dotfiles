macOS → [Fresh Mac](/docs/fresh-mac). Linux → thin `./setup.sh` → `rig/bootstrap/linux.sh`.

```bash
./setup.sh --dry-run --verbose
./setup.sh
exec zsh -l
```

| Flag | Effect |
| --- | --- |
| `--dry-run` | Plan only |
| `--verbose` | Debug log |
| `--smoke-check` | Verify only |

```mermaid
flowchart LR
  A["./setup.sh"] --> B{Mode}
  B -->|dry-run| C[Plan]
  B -->|smoke| D[Verify]
  B -->|apply| E[Mutate → smoke]
```

Needs: Linux x86_64/arm64, bash/git/curl, sudo, apt, network. After CLI shims, setup delegates the agent stack to `just bootstrap-dev` (wyattowalsh/agents) with `--skip-mcphub`. Apply **fail-closes** if the wrapper or installer fails. `--smoke-check` fails if the wrapper file is missing. It does not run a hardcoded `npx skills add` list. Harness/MCP JSON stays in [agents](https://github.com/wyattowalsh/agents). See [AI](/docs/ai-harness).
