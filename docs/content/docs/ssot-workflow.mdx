Live Mac = inventory. Commit only curated manifests.

```mermaid
flowchart LR
  A[Live] --> B["inventory-redacted"]
  B --> C["local/"]
  C --> D[Diff]
  D --> E[Promote]
  E --> F["just check"]
  F --> G["bootstrap --apply"]
```

```bash
just inventory-redacted   # → ignored local/*
# edit rig/brew, rig/home, rig/dots, rig/darwin as needed
just check
just bootstrap --dry-run
just bootstrap --apply
```

`local/` never commits. Details: [Brew](/docs/packages), [Map](/docs/domain-map), [Security](/docs/security).
