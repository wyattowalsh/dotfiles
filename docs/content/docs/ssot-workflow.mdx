description: How to treat the live Mac as inventory and promote curated desired state.
---

The live `w4w-mbp` rig is **inventory**, not something to commit wholesale. Promote intentional changes into tracked manifests after review.

## Workflow

```mermaid
flowchart LR
  A[Live machine] --> B[just inventory-redacted]
  B --> C[local/ artifacts]
  C --> D[Diff vs repo]
  D --> E[Curate + promote]
  E --> F[just check]
  F --> G[just bootstrap --apply]
```

## Step 1 — Refresh inventory

```bash
just inventory-redacted
```

Writes ignored artifacts under `local/`:

| Artifact | Contents |
| --- | --- |
| `local/Brewfile.raw` | Raw `brew bundle dump` (evidence only) |
| `local/config-dirs.txt` | Redacted `~/.config` directory listing |
| `local/zsh-inventory.txt` | Redacted zsh overrides, functions, completions |

No file contents or secret-shaped values are copied.

## Step 2 — Diff live vs repo

```bash
cmp -s .zshrc home/dot_zshrc.tmpl && echo "zshrc parity OK"
cmp -s .p10k.zsh home/dot_p10k.zsh && echo "p10k parity OK"
just brew-check
just home-diff
```

`just check-zsh` enforces root ↔ Chezmoi mirror parity in CI.

## Step 3 — Promote by domain

| Domain | Source of truth | Promotion target |
| --- | --- | --- |
| Shell | `~/.zshrc`, `~/.p10k.zsh` | Repo root + `home/dot_zshrc.tmpl`, `home/dot_p10k.zsh` |
| Git | `~/.gitconfig` | `.gitconfig` at repo root |
| Home config | `~/.config/*` | `home/private_dot_config/` templates |
| Packages | `local/Brewfile.raw` | Curated `brew/Brewfile` groups |
| System | Host-specific nix | `darwin/hosts/w4w-mbp/` |

Classify each Brew entry by intent (core CLI, dev language, AI tool, cask, font, service) before adding to `brew/Brewfile`.

## Step 4 — Validate and apply

```bash
just check
just bootstrap --dry-run
just bootstrap --apply   # macOS only, after review
```

## Chezmoi vs root symlinks

| Path | Deploy mechanism |
| --- | --- |
| `.zshrc`, `.p10k.zsh`, `.gitconfig` | `bootstrap/macos.sh` symlinks from repo root |
| `~/.config/ghostty`, lazygit, yazi | Chezmoi templates under `home/` |
| `dot_zshrc.tmpl`, `dot_p10k.zsh` | Parity mirrors only — listed in `home/.chezmoiignore` |

See [Home configuration](/docs/home-config) for template and override rules.
