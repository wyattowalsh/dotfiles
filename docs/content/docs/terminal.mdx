SSOT: `rig/home/private_dot_config/ghostty/config.tmpl`. Fonts: Nerd Font casks in `rig/brew/Brewfile`.

The tmpl enables contextual alternates with `font-feature = calt`, disables standard ligatures with `font-feature = -liga`, generates the palette, includes an optional `config.local` (`config-file = ?config.local`), and uses native bell audio. The bell sound file stays local (`~/.config/ghostty/sounds/`). Backgrounds: `~/.config/ghostty/backgrounds/` (local only).

Ghostty owns everyday splits. The tracked tmux formula exists only as Agent Deck's backend. Left Option is mapped to Alt for bindings such as Yazi's DuckDB preview keys.

```bash
just home-diff
ghostty +validate-config
```
