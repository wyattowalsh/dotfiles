SSOT: `rig/brew/Brewfile`. Excludes: `rig/brew/exclude.txt`. Dumps under `local/` are evidence only.

```bash
just inventory-redacted
just brew-check
```

`rig/brew/Brewfile` is the package SSOT. `rig/darwin/modules/packages.nix` is a tiny nix-darwin bootstrap CLI set (`bash`, `curl`, `git`, `jq`, `ripgrep`); overlap with those Brewfile formulae is OK.

## Groups

Comment group headers in `rig/brew/Brewfile`:

| Header | Section |

| `core-cli` | Core CLI formulae |
| `shell-plugins` | Zsh plugin formulae |

| `dev-languages / containers` | Languages, build tools, optional colima |
| `ai-tools` | AI CLI tooling |
| `media-cli` | Media conversion CLI |
| `data / db` | Database servers |

| `mas — selected App Store apps (requires Apple ID on target Mac)` | Selected Mac App Store apps |

## Policy

| Topic | Rule |
| --- | --- |
| Docker | Primary is `cask "docker-desktop"`. `brew "colima"` is optional secondary — do not run both engines together. Formula `docker` stays in `exclude.txt`. |
| Kopia | CLI is `kopia/test-builds/kopia` (nightly job). Keep the `kopia/test-builds` tap. `kopiaui` cask is manual restore only. |
| VS Code | Extension lines are inventory only under `local/` — not tracked in the Brewfile. |

Promote curated names only. See [Promote](/docs/ssot-workflow), [Backup](/docs/backup).
