`rig/brew/Brewfile` is the **transfer-oriented desired state** for the personal Apple Silicon rig: formulae, casks, selected Mac App Store apps (`mas`), taps, fonts, and Quick Look plugins.

Raw dumps under gitignored `local/` are **evidence only** — never commit them. Review with `just inventory-redacted` before promoting more entries. Junk installers/auto-updaters live in `rig/brew/exclude.txt`.

## Validate

```bash
just inventory-redacted   # local/Brewfile.raw, local/mas.raw, local/apps-all.txt, …
just brew-check           # brew bundle check --file rig/brew/Brewfile
```

## Layered ownership

| Layer | Owns | Does not own |
| --- | --- | --- |
| Homebrew Bundle | Broad CLI, **all GUI casks**, selected **mas**, fonts/QL | System `defaults`, AI MCP secrets |
| nix-darwin | Platform, `system.defaults`, tiny system packages | Full GUI catalog |
| mise + uv | Language/runtime versions | Every historical language manager |
| agents repo | Harness / MCP client configs | This Brewfile |

## Brewfile groups (high level)

| Group | Examples | Notes |
| --- | --- | --- |
| `core-cli` | `ripgrep`, `fd`, `fzf`, `uv`, `gh`, `just` | Daily terminal tooling |
| `dev-languages` | `mise`, `node`, `go`, `bun`, `deno`, `colima` | Runtimes; **mise** pins versions on host |
| containers | `cask "docker-desktop"` (primary), optional `colima` | Do **not** run Desktop and Colima engines together; formula `docker` is excluded |
| `shell-plugins` | `zsh-autosuggestions`, `zsh-syntax-highlighting` | Homebrew formulae (not OMZ plugin clones) |
| `ai-tools` | `ollama`, `stripe`, `supabase` | AI and platform CLIs |
| GUI cask sections | browsers, editors, comms, media, desktop util | Full-transfer intent |
| `fonts` / `quicklook` | Nerd Fonts, QL plugins | Finder/terminal polish |
| `mas` | Things, Bear, Xcode, … | Requires Apple ID on the target Mac |

Editor extensions (`vscode "…"` lines) may appear in **local** dumps only — they are **not** mass-promoted into the tracked Brewfile.

## Taps

Third-party taps are listed only when a promoted formula/cask needs them (for example `oven-sh/bun`, `stripe/stripe-cli`, `supabase/tap`, `hashicorp/tap`). Unused and test-channel taps (for example `kopia/test-builds`) are pruned. Prefer official bottles/casks; expect Homebrew trust prompts for non-core taps.

`rig/brew/exclude.txt` is enforced by `checks/brew-exclude-check.sh` (run from `just brew-check`).

## Services

Only intentional always-on agents use `restart_service: true` (for example `pueue`). Leave databases and cloud daemons stopped unless you deliberately promote them.

## Bootstrap install flags

On a **new Mac**, prefer a no-upgrade first pass with parallel formula jobs:

```bash
just bootstrap --apply --no-upgrade
```

`rig/bootstrap/macos.sh` passes `brew bundle install --jobs auto` and optional `--no-upgrade`.

**Do not** run `brew bundle cleanup` against this transfer Brewfile unless you intentionally want to uninstall everything else.

## Promotion checklist

1. `just inventory-redacted` → inspect `local/` only  
2. Classify: promote / exclude (`rig/brew/exclude.txt`) / manual (docs)  
3. Edit `rig/brew/Brewfile` groups  
4. `just brew-check`  
5. `just bootstrap --dry-run` then `--apply` after review  

Never commit secrets, emails, absolute home paths, or raw inventory dumps. See [SSOT workflow](/docs/ssot-workflow) and [Fresh Mac](/docs/fresh-mac).
