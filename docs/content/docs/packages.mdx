SSOT: `rig/brew/Brewfile`. Excludes: `rig/brew/exclude.txt`. Dumps under `local/` are evidence only.

```bash
just inventory-redacted
just brew-check
```

`rig/brew/Brewfile` is the package SSOT. `rig/darwin/modules/packages.nix` is a tiny nix-darwin bootstrap CLI set (`bash`, `curl`, `git`, `jq`, `ripgrep`); overlap with those Brewfile formulae is OK.

## Policy

| Topic | Rule |
| --- | --- |
| Upgrades | `freshen` / `fr` is the upgrade operator (greedy casks, skip-casks pins, mas, caches). Do not ad-hoc `brew upgrade`. See [freshen](/docs/freshen). |
| Docker | Primary is `cask "docker-desktop"` on the MBP rig. `brew "colima"` is optional secondary — do not run both engines together. Formula `docker` stays in `exclude.txt`. For the MBA migration this Brewfile is **intent, not an MBA installer**: retain existing CLI/auth, prove capacity, separately approve a signed fresh Apple Silicon Desktop with measured VM caps and disk placement, then verify a new engine over a pinned SSH context. Old-VM removal alone is not fresh-engine proof. |
| Kopia | Retain the MBP's `kopia/test-builds/kopia` CLI, tap and 04:00 job; KopiaUI is its manual restore interface. On the MBA, KopiaUI owns the hourly policy and native login startup for its separate encrypted Drive repository. Do not install a second nightly scheduler or apply the MBP GUI-disable rule there. rclone stays the Google Drive backend; `s5cmd` is high-throughput S3/local — do not retarget Kopia. See [Backup](/docs/backup). |
| Pueue | Keep the CLI installed with `restart_service: false`. The MBA music contract owns its isolated scheduler; Brew Bundle must not restart a retired MBP scheduler or create a second MBA owner. Existing MBP backup/workstation jobs are unaffected by this source policy. |
| VS Code | Extension lines are inventory only under `local/` — not tracked in the Brewfile. |
| Runners | `just` is the only task runner (Brew binary; do not install via mise). `mise` is toolchain shims only — no repo-root `mise.toml` and no mise `[tasks]`. `go-task` stays inventory leftover. direnv is env + `layout_uv`, not versions. |
| HTTP | `curl` stays for scripts; `xh` is interactive HTTP. Do not `apt install yq` on Debian — that is a different binary. |
| Atuin | Local-only. Atuin Cloud / `atuin login` is out of scope. |
| Deferred | **Gita** — wait until this repo tracks global `uv tool` installs. |

Promote curated names only. See [Promote](/docs/ssot-workflow), [Shell](/docs/shell), [Backup](/docs/backup), [Terminal](/docs/terminal).
