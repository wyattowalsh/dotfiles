## Native profile

`IINA-Native.conf` keeps direct mpv/IINA actions. The installed 1.5.0-beta2 app and its real hardware behavior still need visual acceptance **after the applied migration**. Numeric scroll values below describe the current desired state; they are not a guarantee across IINA versions.

| Input | Intended direct action |
| --- | --- |
| `a` / Left · `d` / Right | Seek ±10 seconds; Shift seeks ±5 exact; Cmd+Shift seeks ±1 exact |
| Unmodified vertical/horizontal wheel | Pan via `WHEEL_*` mpv bindings when IINA forwards scroll to mpv (actions 3/3); confirm both axes in beta2 |
| `[` `]` · `{` `}` · Backspace | Adjust or reset speed; wheel is not a speed shortcut |
| `o` · Shift+`o` · Ctrl+`p` | Time/percent OSD, media title, playlist shuffle |
| Ctrl+`1…8` | Deliberate brightness/contrast/gamma/saturation changes; plain digits are ignored |
| `s` · `l` | Screenshot and A–B loop |
| Cmd+`u` · Shift+Cmd+`u` · Ctrl+`u` | Opt-in FSRCNNX quality/fast and custom-shader off |
| Alt+`1/2/3` · Shift+Alt+`1/2/3` | Opt-in Anime4K fast/HQ modes A/B/C |

**Not native in this migration:** pointer-anchored Cmd+scroll zoom, zoom presets, plugin reset/rotation menus, synthetic middle-mouse/F15–F20 bridge and its fail-closed cursor behavior. They are not silently mapped to center-zoom. The root `cursor-actions.md` is a future **standalone plugin handoff**, not an installed feature.

`mpv.conf` stays minimal with no global shader chain. `shaders-pin.json` records Anime4K and FSRCNNX source/tag/file SHA-256; GPL `.glsl` files are downloaded outside Git only by a separately approved `just iina-shaders install --apply`. `just iina-shaders doctor` checks local assets; `restore --apply` is another separately reviewed action. Both optional installers now take the shared operation lock, require IINA quit before mutating, limit archive resource usage, verify a per-file SHA-256 manifest for a completed local snapshot before restore, and keep a checked pre-restore rescue of their managed targets for error recovery. This detects accidental backup drift, not a same-user adversary able to edit both a snapshot and its unsigned manifest; a second INT/TERM is ignored during recovery, while a hard kill, power loss, or failed copy can still require manual inspection of a dirty rescue. If shaders miss frame deadlines, use mpv stats (`Shift+i`, page 2), choose a fast chain, or clear shaders with Ctrl+`u`.

Current desired IINA preferences include user-defined mpv config, screenshot options, thumbnails, AVFoundation audio, fullscreen-on-open off, and scroll pass-through. Historical CoreAudio/fullscreen observations came from earlier beta testing. Recheck audio-device topology, fullscreen behavior, remote-thumbnail I/O and the meaning of scroll actions in **1.5.0-beta2** before deciding whether each setting remains worthwhile.

## Acceptance and security

Keep the signed beta if it remains stable on this Mac. IINA's current stable [1.4.4 release](https://github.com/iina/iina/releases/tag/v1.4.4) fixed [GHSA-w5xh-98j7-jp5q](https://github.com/iina/iina/security/advisories/GHSA-w5xh-98j7-jp5q) affecting older `iina://` URL handling; continue rejecting untrusted protocol prompts. [IINA's downloads](https://iina.io/download/) distinguish stable and beta, while [plugin documentation](https://docs.iina.io/pages/dev-guide.html) describes plugin capabilities. The separate [mpv manual](https://mpv.io/manual/master/#configuration-files) is reference material, not proof of IINA beta integration.

Post-migration acceptance is still pending: use a visible beta2 player to test profile selection, seeking, both wheel axes and modifier pass-through, screenshots/subtitles, A–B loop, opt-in shaders/off and timing, thumbnails, audio/fullscreen, responsiveness and preservation of all other plugins and credentials. Confirm the retired QoL plugin and event tap no longer load. If an acceptance check fails, stop and review the exact migration snapshot before restore; do not claim the deferred cursor actions are working.
