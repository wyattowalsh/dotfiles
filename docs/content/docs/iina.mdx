```bash
just check-iina-config
just iina-qol preview
just iina-qol apply --apply
just iina-qol doctor

just iina-shaders preview
just iina-shaders install --apply
just iina-shaders doctor

just iina-plugins install --apply
```

All three workflows are dry-run unless `--apply`. `iina-qol` writes tracked files and native preferences; the shader/plugin installers download only pinned GitHub release assets, verify SHA-256 and archive structure, then keep timestamped backups for `restore --apply`. Quit IINA before installing/restoring plugins.

## Image quality

Shader selection is per-session and opt-in. Start with **FSRCNNX quality** (`Cmd+u`) for film/live-action. For anime, try modes A→B→C and keep the least aggressive mode that improves the source. Fast (`Alt+1/2/3`) is the M1 Pro default; HQ (`Shift+Alt+1/2/3`) costs more GPU. `Ctrl+u` clears all custom shaders. Use `Shift+i`, then page 2 in mpv stats to inspect shader timing and drop to fast/off if rendering misses frame deadlines.

Pinned native IINA preferences enable the user config directory, 480px timeline thumbnails, a 1 GiB thumbnail cache, mounted-remote-drive thumbnails, and IINA's AVFoundation audio driver. AVFoundation is intentional on this machine: CoreAudio fails channel-layout initialization against the current multi/virtual-device topology, while AVFoundation initializes cleanly. Fullscreen-on-open stays off because IINA 1.5.0-beta1 can fail the AppKit fullscreen transition and leave the loaded player window inaccessible; use `f` after the window appears. Remote thumbnails can consume network/storage I/O; turn that preference off locally if a slow mount suffers.

## Rules

| Rule | Detail |
| --- | --- |
| Tap | Hammerspoon scroll tap defaults **on**; consumes only Command±Shift scroll (Command required, Shift optional; alt/ctrl/fn and unmodified scroll pass through) |
| Cursor zoom | Player-space pointer from IINA mouse callbacks (Hammerspoon middle-mouse poke before F17–F20) or mpv `mouse-pos` with `hover === true`. Synthetic F-key origin is ignored. Missing pointer is fail-closed. Never call center-zoom “cursor zoom”. Pin IINA `middleClickAction` to **none (0)** — **4 is togglePIP** and turns that poke into Picture-in-Picture |
| Shaders | No global chain. `shaders-pin.json` records GPL-3.0 GitHub sources + hashes; downloaded `.glsl` files stay untracked and every keymap reference must be pinned |
| Official plugins | Only `iina/plugin-*` release assets in `official-plugins-pin.json`; hashes + manifests checked before install; runtime `.data` / `.preferences` preserved |
| Apply | Exact-target `just iina-qol apply --apply` — not a full home/bootstrap apply |
| Untracked | Downloaded shader/plugin packages, overlay, history, plugin prefs, sibling plugins, logs, screenshots — dest paths in `.chezmoiignore` |
