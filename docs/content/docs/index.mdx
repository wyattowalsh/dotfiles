## Command surface

`justfile` is canonical. Prefer `just <name>` over ad hoc shell recipes.

```bash
just --list
just check          # static validation (shell, zsh parity, freshen, JSON, secrets scan)
just ci             # full CI parity: check + smoke + docs build
just bootstrap --dry-run
```

## What belongs in Git

- Curated manifests: `brew/Brewfile`, `darwin/`, `home/`, root dotfiles, `.env.example` (names only)
- Runbooks and agent instructions in `docs/`, `AGENTS.md`, and `.github/instructions/`

## What stays local

- Tokens, API keys, OAuth files, bearer secrets
- Raw `brew bundle dump` output (`local/Brewfile.raw`)
- App caches, histories, telemetry, session databases
- Ghostty background assets under `~/.config/ghostty/backgrounds/`

## Platform entrypoints

| Platform | Bootstrap | Notes |
| --- | --- | --- |

| Debian/Ubuntu Linux | `./setup.sh` | apt-based legacy path; AI CLI + skills install |
