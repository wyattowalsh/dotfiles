## Command surface

`justfile` is canonical. Prefer `just <name>` over ad hoc shell recipes.

```bash
just --list
just check          # static validation
just ci             # full CI parity: check + smoke + docs build
just bootstrap --dry-run
```

## What belongs in Git

- Curated manifests: `rig/brew/Brewfile`, `rig/darwin/`, `rig/home/`, `rig/dots/`, `.env.example` (names only)
- Operator runbooks in this site (`docs/content/docs/`)
- Agent contracts in nested `AGENTS.md` (not operator prose)

## What stays local

- Tokens, API keys, OAuth files, bearer secrets
- Raw `brew bundle dump` output (`local/Brewfile.raw`)
- App caches, histories, telemetry, session databases
- Ghostty background assets under `~/.config/ghostty/backgrounds/`

## Platform entrypoints

| Platform | Bootstrap | Notes |
| --- | --- | --- |
| Apple Silicon macOS | `just bootstrap` → `rig/bootstrap/macos.sh` | Brew + `rig/dots` symlinks + Chezmoi + nix-darwin |
| Debian/Ubuntu Linux | `./setup.sh` | apt-based path; AI CLI + skills install |
