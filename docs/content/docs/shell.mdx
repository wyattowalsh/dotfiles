```bash

```

`just check-zsh` runs `zsh -n` (when `zsh` exists), `cmp` of dots ↔ Chezmoi parity mirrors, **`checks/zsh-structure-test.sh`**, then `checks/zsh-structure.sh rig/dots/zshrc all`.

| Behavior | Live rule |
| --- | --- |
| `timeout` alias | Guarded: `command -v gtimeout && alias timeout='gtimeout'`. Unguarded `alias timeout=` fails L0. |
| nvm | Sourced if `$NVM_DIR/nvm.sh` exists (Linux bootstrap). |
| mise | `mise activate zsh` when `mise` is on `PATH` (wins if both nvm and mise exist). |
| Linux OMZ plugins | `linux.sh` clones p10k, zsh-autosuggestions, and zsh-syntax-highlighting under `$ZSH_CUSTOM`. `zshrc` prefers Homebrew shares, then that custom path. macOS bootstrap does not clone the brew-managed plugins. |
