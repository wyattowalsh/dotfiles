# AGENTS

## Scope
Topic-oriented dotfile modules.

## Rules
- Keep topic modules cohesive; do not mix unrelated config domains.
- Every topic should document install/apply behavior and validation.
- Prefer portable config plus local override hooks over hardcoded machine state.
- Do not duplicate source-of-truth manifests from `brew/`, `ai/`, `home/`, or `darwin/`; link to them instead.
