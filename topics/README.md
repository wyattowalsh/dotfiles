# Topics

Topic directories group related dotfiles and bootstrap logic in the style of mature topic-oriented dotfile repos.

Initial topic set:
- `shell`
- `git`
- `terminal`
- `editors`
- `macos`
- `packages`
- `ai`
- `mcp`
- `docs`
- `security`

Each topic should own its install notes, managed files, local override policy, and validation expectations.
